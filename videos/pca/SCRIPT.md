## 逐頁腳本

### P1｜封面（0–16s，T0 黑底）
* **字卡**：主成分分析 PCA／看見咖啡 FTIR 光譜裡的品種指紋
* **字級**：標題 128px / 副標 52px
* **旁白**：傅立葉轉換紅外光譜，FTIR，是食品分析裡最快速的「化學掃描儀」。它能把一支咖啡，變成 286 個波數的吸收指紋。但這 286 個數字，我們要怎麼讀懂？這個系列，就從主成分分析 PCA 開始。
* **字幕**：FTIR 把咖啡變成 286 個波數的吸收指紋

### P2｜紅外光譜怎麼測咖啡（16–38s，T3 SVG）
* **視覺**：三步流程圖逐步亮起 — ① 咖啡粉樣本 → ② FTIR 儀器（DRIFT 模式） → ③ 286 點光譜（樣本×波數矩陣）
* **字卡**：樣本 → FTIR-DRIFT → 光譜矩陣
* **旁白**：在食品分析裡，FTIR 常這樣用。把咖啡粉放進儀器，紅外光掃過，每一個分子鍵在特定波數吸收能量，最後整理成一條曲線：X 軸是波數，單位 cm⁻¹，Y 軸是吸收值。今天的資料，56 支即溶咖啡，就是這樣來的。
* **字幕**：FTIR 掃描咖啡粉，生成波數 vs 吸收值曲線

### P3｜286 個波數的難題（38–58s，T1 大圖）
* **視覺**：ft01_raw_spectra.png（Arabica teal / Robusta coral 的原始光譜折線）
* **字卡**：56 支咖啡 × 286 個波數
* **旁白**：這是 Mendeley Data 公開的即溶咖啡 FTIR 資料：56 支，包含 29 支 Arabica 和 27 支 Robusta。畫成這樣，每一條折線，就是一支咖啡的光譜指紋。問題來了：每支咖啡，是 286 維空間裡的一個點，人眼根本看不出哪些像、哪些不像。
* **字幕**：每支咖啡是 286 維的一點，眼睛看不出來

### P4｜SNV 前處理（58–76s，T2 左圖右文）
* **視覺**：左 ft01 原始（基線飄移）→ 右 ft02 SNV 後（基線對齊，品種分帶清晰）
* **字卡**：散射校正：SNV
* **旁白**：分析前要先整理。DRIFT 模式量到的光譜，有基線飄移和散射效應，同一支咖啡不同批次量就可能偏移。SNV，標準正常變量法，先計算每條光譜的平均和標準差，把每一點都標準化，讓所有光譜站在同一基線上。這一步，等同近紅外的 SNV 前處理，是 DRIFT 分析的標準作法。
* **字幕**：SNV 消除散射基線，光譜站上同一起跑點

### P5｜PCA 的直覺（76–96s，T3 SVG）★
* **視覺**：散布點雲 → PC1 沿最大分散方向畫出 → PC2 垂直彈出
* **字卡**：找出資料最分散的方向
* **旁白**：主成分分析的想法很直覺。把所有咖啡，想成一團散開的點。PCA 要找出這團點最分散的方向，當作第一主成分 PC1；再找一個跟它垂直、第二分散的方向，當作 PC2。新的座標軸，永遠對準資訊最多的方向。
* **字幕**：PC1＝最大分散方向，PC2 與它垂直

### P6｜分數與負荷量（96–115s，T4 公式）
* **視覺**：KaTeX `X \approx T P^{\top}`，T、P 分別高亮
* **字卡**：分數 T、負荷量 P
* **旁白**：用數學講，PCA 把資料矩陣 X，拆成分數 T，乘上負荷量 P 的轉置。分數，是每支咖啡在新座標上的位置；負荷量，告訴我們每一個波數，怎麼組成這些新方向。一個看樣本，一個看波數的貢獻。
* **字幕**：X ≈ T·Pᵀ：分數看樣本，負荷量看波數

### P7｜要留幾個成分？（115–135s，T1 大圖）★
* **視覺**：ft03_pca_scree.png（bars 升起 + coral 累積線繪製，標注 PC1=44.5%, 前2=67.6%, 前3=76.3%）
* **字卡**：陡坡圖：光譜比代謝指紋更集中
* **旁白**：要保留幾個主成分？看陡坡圖。FTIR 光譜中相鄰波數高度相關，所以資訊比代謝組學更集中：PC1 就佔 44.5%，前兩個加起來 67.6%，前三個達 76.3%。光是前兩個主成分，就已經掌握了最重要的品種結構。
* **字幕**：PC1=44.5%，前 2 個累積 67.6% 就夠

### P8｜分數圖：品種浮現（135–157s，T1 大圖）★ 核心
* **視覺**：ft04_pca_scores.png（Arabica teal / Robusta coral，95% 橢圓，PC2 方向主要區分）
* **字卡**：每個點＝一支咖啡，顏色＝品種
* **旁白**：把每支咖啡畫在 PC1、PC2 上，神奇的事發生了：PCA 從頭到尾，都不知道品種，兩種咖啡卻自己依品種聚在一起——Arabica 一群，Robusta 另一群。主要靠 PC2 區分。結構，自己浮現了。
* **字幕**：PCA 不看品種，咖啡卻依品種自動分群

### P9｜負荷量回連化學（157–177s，T2 左圖右文）
* **視覺**：ft05_pca_loadings.png（PC1 teal 線，PC2 coral 線，1714 / 1710 / 1706 cm⁻¹ 高亮）
* **字卡**：負荷量說的是紅外化學
* **旁白**：那是哪些波段，讓品種分開？看負荷量。PC1 貢獻最大的波段，集中在 1714、1710、1706 cm⁻¹——這是羰基和脂質 C=O 的伸縮振動區。Arabica 和 Robusta 的脂質組成不同，紅外光譜把這個差異翻譯出來了。
* **字幕**：1714 / 1710 / 1706 cm⁻¹ = 羰基脂質 C=O 振動區

### P10｜什麼是指紋區？（177–196s，T3 SVG）
* **視覺**：810–1911 cm⁻¹ 光譜示意，標示指紋區（fingerprint region），主要官能基振動類型
* **字卡**：810–1911 cm⁻¹ 指紋區
* **旁白**：為什麼要用這個範圍？中紅外的 810 到 1911 波數，是所謂的「指紋區」。就像人的指紋，每一種食品在這個範圍的吸收模式，都是獨一無二的。它包含了 C–O、C–C、C–N 等骨架振動，任何微小的化學差異，都會留下痕跡。
* **字幕**：810–1911 cm⁻¹ 指紋區：每種食品的獨特化學簽名

### P11｜PCA 是 / 不是（196–212s，T5 卡片）
* **視覺**：三張卡片逐塊淡入
  - 卡片 1：**非監督** — 不需要品種標籤
  - 卡片 2：**擅長** — 探索、分群、找異常
  - 卡片 3：**不做** — 不直接鑑別品種
* **字卡**：認清 PCA 的定位
* **旁白**：要記得，PCA 是非監督式的：它只看光譜本身，不需要任何標準答案。它擅長探索、分群、找異常；但它不會直接告訴你，這支咖啡是 Arabica 還是 Robusta。那，是下一支影片的任務。
* **字幕**：PCA 非監督：探索分群找異常，不做鑑別

### P12｜知識地圖（212–231s，T3 SVG）★
* **視覺**：中心輻射 — FTIR 光譜 → SNV 前處理 →（分數 / 負荷量 / 陡坡）三分支
* **字卡**：PCA 探索流程全圖
* **旁白**：把流程串起來：FTIR 光譜，先做 SNV 散射校正，再用 PCA，拆成分數、負荷量、和陡坡圖。分數看分群和品種結構、負荷量看哪個波段在貢獻、陡坡圖決定要保留幾個主成分。這就是用 PCA 探索咖啡 FTIR 資料的完整地圖。
* **字幕**：光譜 → SNV → PCA → 分數 / 負荷量 / 陡坡
